✨ CORE FEATURES

01

Self-Hosted & Lightweight

Powered by Express.js and an embedded SQLite database (storage/database.sqlite) for seamless portability.

02

Telegram Bot Integration

Seamlessly maps visitor chat sessions and routes admin replies using native Telegram message replies.

03

Domain Whitelisting Security

Protects your widget from unauthorized embedding on third-party websites by validating request origins.

04

Apple-Inspired UI & Logs

Clean, minimalist design with a Laravel-like centralized error middleware logging system exceptions.

🚀 INSTALLATION

Clone and setup Firefine locally straight from your terminal:

git clone https://github.com/nitefine/firefine.git && cd firefine && npm install

🕹️ SETUP & RUN REFERENCE

Action / Step Description Command
Clone Repo Clones the Firefine repository to your local machine.
git clone https://github.com/nitefine/firefine.git
Install Packages Installs all required project dependencies.
npm install
Development Mode Starts the application server for local testing.
npm run start
Production (PM2) Runs the application continuously in the background using PM2.
pm2 start src/app.js --name "firefine"
