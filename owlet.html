OWLET CLI

Cross-platform CLI tool that prevents your operating system from going to sleep while running heavy tasks like builds, benchmarks, and data transfers.

✨ CORE FEATURES

01

Cross-Platform Native Support

Utilizes native system utilities under the hood (caffeinate on macOS, systemd-inhibit on Linux, and PowerShell API on Windows).

02

Zero-Dependency Reliability

Built lightweight using standard OS capabilities without needing heavy background daemons or extra background services.

03

Smart Lifecycle Management

Automatically instructs your OS to stay awake until your custom command completes, then safely restores your power management settings.

04

Instant Execution via NPX

Run it instantly on the fly without permanent installation, or install globally to use it smoothly anywhere in your terminal.

🚀 INSTALLATION

Run Owlet directly on the fly using npx or install it globally from the npm registry:

npm install -g owlet

🕹️ CLI COMMAND REFERENCE

Command Description Example
owlet --command Wraps and executes your intensive terminal task while preventing OS sleep.
owlet --command "npm run build"
npx owlet --command Executes the tool instantly without permanent global installation.
npx owlet --command "node benchmark.js"
